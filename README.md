# 剪贴板Pro —— 单机剪贴板管理器

Windows 桌面端本地剪贴板管理器。**纯单机、不联网、零云端依赖**，
把系统剪贴板从"一个临时缓冲区"变成"一个可检索、可组织的本地信息库"。

- 实现语言：**Python 3.12**（标准库 + Pillow + pywin32）
- 本阶段目标：第一周 ~ 第二周上半段，做出**可运行、可测试的雏形**（主链路做深做稳）

## 二、快速开始

### 环境要求

| 项 | 要求 | 本机实测 |
|---|---|---|
| 操作系统 | Windows 10 / 11 | Windows（已验证） |
| Python | 3.10 及以上 | 3.12.5 |
| 第三方库 | `pillow`、`pywin32` | 已安装 |

```bat
pip install pillow pywin32
```

> 界面、数据库、剪贴板监听、图片处理全部可用标准库 + 上面两个库完成，
> **不需要任何联网组件**，也不需要 Node / Rust / 数据库服务。

### 运行

```bat
cd 1st
python -m app.main --show
```

| 参数 | 作用 |
|---|---|
| `--show` | 启动后立刻显示主面板（不加则静默驻留托盘，符合默认配置） |
| `--no-listener` | 不注册剪贴板监听与全局快捷键（调试界面用） |
| `--data-dir <路径>` | 指定数据目录（默认 `<1st>/.data`） |

也可以直接双击 `启动剪贴板Pro.bat`（推荐给日常使用）。

> **项目目录名是 `1st`（ASCII）。** 之前叫 `开发` 时踩到过一类坑：
> `pythonw.exe` 在含中文的路径下会以退出码 2 直接失败。
> 现在启动器仍然用 `DETACHED_PROCESS` 而不是 `pythonw`，
> 因为它对路径不做任何假设 —— 将来谁把目录改成中文名也不会突然启动失败。
>
> **关于终端**：启动器会用「脱离控制台」的方式把程序放到后台，
> 打印完提示后自动关掉黑窗口。**关掉终端不影响程序**——
> 托盘图标和全局快捷键都还在，这是刻意设计的（见 `文档/设计说明.md`）。
>
> ⚠️ 如果双击后**黑窗口一闪就没了、程序没起来**，说明这个 `.bat` 的换行符
> 被某个编辑器或 Git 改成了 LF。cmd 只认 CRLF 换行，遇到 LF 会把
> 启动命令那一行吞掉（详见 `文档/运行说明.md` 的 Q0）。
> 一条命令自查：`python tests\check_launchers.py`。
> 兜底办法：直接 `python -m app.main --show`。

### 上手三步

1. 启动后程序驻留托盘，任意软件里按 **`Ctrl+Shift+V`** 唤出面板
2. 在任意软件里复制几段内容（文本、网址、代码、截图都可以），面板里会自动出现卡片
3. 双击卡片 → 面板收起 → 内容自动粘贴回你刚才在用的软件

### 面板窗口怎么操作

面板是一个**标准 Windows 窗口**，不是无边框浮层，所以：

| 操作 | 怎么做 |
|---|---|
| 移动面板 | 拖标题栏（或拖面板空白处） |
| 改大小 | 拖窗口边缘，宽度高度都会被记住 |
| 最小化 | 标题栏的最小化按钮，或面板内的 `—`，或 `Ctrl+M` |
| 收起面板 | 标题栏的关闭按钮、面板内的「收起」、`Ctrl+W` 或 `Esc` |
| 打开设置 | `Ctrl+,` 或面板里的「☰ 操作」菜单 |

> **关闭 ≠ 退出程序。** 点关闭按钮只是把面板收起来，程序仍在托盘运行，
> 全局快捷键随时可以再唤出来。真正退出要用**托盘图标右键 → 退出**。
> 这样设计是因为剪贴板管理器需要常驻才能记录，误关一下就退出会很难用。

### 键盘操作

| 按键 | 作用 |
|---|---|
| `Ctrl+Shift+V` | 唤出 / 收起主面板（全局快捷键，可在设置里改） |
| `Ctrl+Shift+F` | 唤出面板并聚焦搜索框 |
| `↑` / `↓` | 上下选择 |
| `Enter` / 双击 | 粘贴选中项 |
| `Ctrl+1` ~ `Ctrl+9` | 直接粘贴当前列表第 1~9 条 |
| `Ctrl+P` | 置顶 / 取消置顶 |
| `Ctrl+E` | 编辑内容 |
| `Delete` | 删除选中项（二次确认） |
| `Ctrl+F` / `Esc` | 聚焦搜索 / 收起面板 |
| `Ctrl+W` | 收起面板 |
| `Ctrl+M` | 最小化 / 从最小化还原 |
| `Ctrl+,` | 打开设置 |
| `F5` | 刷新列表 |

> **快捷键被占用时会自动换一个。** `Ctrl+Shift+V` / `Ctrl+Shift+F` 是最抢手的
> 组合之一（输入法、截图工具、浏览器扩展都爱用），装个软件就可能被占掉。
> 程序启动时按候选列表逐个尝试，用第一个能注册成功的，
> **并把实际生效的键写回配置、在状态栏与设置里显示出来**，同时弹一次提示。
> 所以状态栏显示的不是 `Ctrl+Shift+V` 时，按它显示的那个键即可 ——
> 也可以在「设置 → 快捷键」里自己指定。

## 五、如实说明（重要）

这些是**当前阶段的已知边界**，不是遗漏，写在这里是为了避免误导：

1. **敏感内容目前是明文落库。** F9-3「敏感记录加密存储」排在下周，
   本阶段只做到了"识别 + 列表脱敏显示"（原文在库里仍是明文）。
   设置面板里也是这么写的。**请勿在共用电脑上用本版本存放密钥。**
2. **界面是 tkinter。** 功能完整、零额外依赖，但视觉表现力弱于 Tauri/Web。
   六套主题的令牌表已经全部就位、切换即时生效，如果需要更精细的视觉，
   建议下周评估换成 PySide6（界面层与内核层已经完全解耦，替换不影响内核）。
3. **列表是分批渲染而不是真正的虚拟滚动。** 每次渲染 60 张卡片，滚到底部继续加载。
   实测 1000 条以内的滚动与检索都流畅；F4 要求的"虚拟滚动"若要严格达标，
   下周可以补一个真正的可视区渲染。
4. **托盘图标用的是系统默认图标。** 换成自定义 `.ico` 只是几行代码，但需要美术资源。
5. **未做打包。** 目前以源码方式运行（`python -m app.main`）。
   要出安装包需要 PyInstaller，建议等界面定型后再做，避免反复打包。
